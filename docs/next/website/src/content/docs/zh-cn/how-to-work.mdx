---
title: 使用 Herdr 的工作方式
description: 在本地、SSH 内或通过远程连接运行 Herdr。
---

在工作所在的地方运行 Herdr,从你所在的任何地方连接。

hc 拥有程序与终端状态。Herdr 的呈现主机和终端客户端负责布局、渲染与输入。查看端或呈现主机分离不会终止源端程序。需要单独安装兼容的上游 hc，见[安装 Herdr](/zh-cn/docs/install/)。

## 本地工作

在项目目录中启动 Herdr:

```bash
herdr
```

Herdr 会自动启动或连接到本地后台会话。你不需要管理 socket。在窗格里照常运行 shell、服务器、测试和智能体。

用 `ctrl+b q` 分离客户端。窗格会继续运行。

之后重新连接:

```bash
herdr
```

停止呈现主机但不停止 hc 程序：

```bash
herdr server stop
```

要终止程序，请明确关闭已绑定窗格并等待确认。呈现主机重启只附加已保存绑定，不启动替代 shell 或智能体。

## 通过普通 SSH 的远程工作

SSH 到有代码和凭据的机器,然后在那里运行 Herdr:

```bash
ssh you@server
herdr
```

这和终端复用器的用法一样。Herdr 呈现主机和 hc 都在远程机器上，hc 拥有 shell 和智能体。用 `ctrl+b q` 分离并断开连接,之后再 SSH 回去,重新运行 `herdr`。

当你本来就工作在 SSH shell 里、在手机或平板的 SSH 客户端上,或者想要最简单的配置时,用这条路径。

## 用手机工作

你不需要 Herdr 手机应用或 Web 仪表盘。在手机上装任意一个 SSH 客户端,连到智能体所在的机器,在那里启动 Herdr:

```bash
ssh you@server
herdr
```

同一个持久的 Herdr 会话就会在手机终端中打开。TUI 会适应窄屏,所以你可以在不离开 SSH 的情况下检查智能体、切换工作区、查看窗格。

在 iPhone 上,[moshi](https://getmoshi.app/) 这类应用表现很好。

## 从本地终端远程工作

要在本地呈现、通过 SSH 使用源端 hc，请保存目标并打开 Herdr：

```bash
herdr machine add workbox --label Workbox
herdr
```

在机器选择器选择 Workbox。设置只检查已安装的 hc，不安装或运行远程 Herdr，也不创建终端程序。恢复及源端文件系统限制见[连接机器](/zh-cn/docs/connecting-machines/)。

本节余下的 `--remote` 示例属于**独立的旧版远程 Herdr 路径**，不是已保存 hc 配置。要明确连接兼容的远程 Herdr，不必先打开 shell：

```bash
herdr --remote workbox
herdr --remote ssh://you@server:2222
```

远程服务器保持窗格运行，并通过 SSH 发送终端内容和会话状态。本地 Herdr 使用本地主题和显示设置绘制 UI。

想让远程会话用起来像本地时,用这条路径。客户端运行在你的机器上,所以图像剪贴板粘贴等本地桌面功能可以桥接到远程服务器。如果你先 SSH 再在服务器上运行 `herdr`,Herdr 就完全运行在那台服务器上,无法读取你本地桌面的剪贴板。

对于经常连接的目标,把主机写进 SSH 配置:

```text
Host workbox
  HostName server.example.com
  User you
  Port 2222
```

然后这样连接:

```bash
herdr --remote workbox
```

## 该用哪条路径

本地工作用 `herdr`；通过 `ssh you@server` 再 `herdr`，可以在源端同时运行呈现与 hc，也适用于手机 SSH 客户端。要在一个窗口本地呈现 Local 和已保存 SSH 源端，用 `herdr machine add <host> --label <label>`，见[连接机器](/zh-cn/docs/connecting-machines/)。明确使用的 `herdr --remote <host>` 保留给旧版远程 Herdr 兼容连接，不用于 hc 设置或迁移。

关于远程引导细节、命名远程会话、自定义二进制和直接终端附加,参见[持久化与远程访问](/zh-cn/docs/persistence-remote/)。
