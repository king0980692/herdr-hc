title: 核心概念
description: 理解 Herdr 的工作区、标签页、窗格、智能体、会话和模式。
---

Herdr 是终端工作区管理器。hc 拥有真实的终端程序与状态，Herdr 围绕精确的源端绑定提供呈现、布局和输入路由。

## 工作区

工作区是最顶层的项目容器。为每个仓库、任务或调查使用一个工作区。

工作区拥有标签页和窗格。它在侧边栏中的状态由内部的智能体汇总而来,让你一眼看出哪个项目需要关注。

## 标签页

标签页是工作区内的一种布局。用标签页来分隔不同视图,比如 `agents`、`logs`、`server` 或 `review`。

标签页可以通过 CLI 和 socket API 寻址。

## 窗格

窗格呈现以永久 core ID 和规范源端本地地址绑定的 hc 终端。Herdr 渲染输出、路由输入，不拥有客户端本地子进程。客户端分离保留绑定；明确关闭只能在确认后终止精确绑定的程序。

窗格可以向右或向下分割。它们可以手动重命名、通过 CLI 读取、接收输入,以及被关闭。

## 鼠标 UI

Herdr 是鼠标原生的。你可以点击窗格、标签页、工作区和智能体,可以拖动分割边框、选择文本、使用右键菜单。下文的所有操作都可以用鼠标完成;按键绑定是可选的一层。

如果你偏好纯键盘操作,或者不想让 Herdr 捕获鼠标输入,可以禁用鼠标捕获:

```toml
[ui]
mouse_capture = false
```

## 智能体

在 hc 窗格中，智能体身份和语义状态来自源端 hc 的明确状态报告，包括 OSC 7501。Herdr 不通过屏幕、客户端本地 PID、旧 hook 或待启动意图推测状态。没有实时附加上的当前报告时，状态为 `unknown`。

智能体状态如下:

| 状态 | 含义 |
| --- | --- |
| `blocked` | 智能体需要输入、审批或决策。 |
| `working` | 智能体正在运行。 |
| `done` | 源端明确报告完成。 |
| `idle` | 源端明确报告空闲。 |
| `unknown` | 当前可用的源端状态缺失或无法识别。 |

查看或聚焦 hc 窗格不会把源端 `done` 改为 `idle`。客户端的关注标记只是呈现，不是源端状态。只有实时上报的状态转换触发通知，重连不重放完成通知。状态既不能证明所有后台任务已完成，也不是批准提示的授权。

## 会话

会话是一个持久的 Herdr 服务器命名空间。默认的 `herdr` 命令连接到默认会话。

Herdr 命名会话是独立的呈现命名空间，不是 hc core 身份：

```bash
herdr session list
herdr session attach work
herdr session attach side-project
```

优先使用工作区。需要独立的呈现窗格、socket 和保存布局时使用命名会话。程序仍属于其 hc 源端；修改 Herdr 会话名不会重定向绑定。

## 客户端与服务器

默认情况下,Herdr 以一个后台服务器加一个或多个已连接客户端的方式运行。

Herdr 主机拥有布局和呈现，客户端是其终端 UI。hc 独立拥有程序、终端状态、cwd 和上报状态。已保存 SSH 机器使用本地 Herdr 呈现，通过 SSH 连接源端 hc，不使用远程 Herdr 渲染。

只有一个客户端连接时,所有标签页会像以前一样采用该客户端的尺寸。连接多个客户端时,每个客户端都可以查看自己的工作区和标签页。不同标签页会分别采用查看它们的客户端尺寸;客户端查看同一标签页时,最后聚焦、选择或操作该标签页的客户端控制其中窗格的尺寸。

用 `ctrl+b q` 分离客户端。服务器和智能体会继续运行。

只停止呈现主机、保留 hc 程序的方法：

```bash
herdr server stop
```

要终止绑定的程序，请明确关闭窗格。关闭结果不确定时保留窗格与绑定。参阅[会话状态与恢复](/zh-cn/docs/session-state/)。

## 模式

Herdr 有终端模式、前缀模式和导航模式。

终端模式把按键发送给聚焦的窗格。前缀模式在按下前缀键后等待一个 Herdr 动作。导航模式是常驻的工作区导航界面。

按下前缀键 (默认 `ctrl+b`),再按一个动作键,比如 `c` 新建标签页,`w` 打开工作区导航。第一次接触前缀键的概念?参见[键盘](/zh-cn/docs/keyboard/)。
