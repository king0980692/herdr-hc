hc 后端版本读取 **hc 默认的共用机器注册表**，不会把这些机器复制进第二份 SSH 清单。你可以在同一个 Herdr 窗口中切换它们的工作区与 Local。**Herdr 在本地渲染；hc 拥有远程程序、终端状态和明确上报的智能体状态。** 已保存机器的设置不会安装、启动或替换远程 Herdr，也不会通过远程 Herdr 渲染界面。

这里有两条独立连接：客户端连接本地呈现主机，呈现主机再通过 SSH 连接 hc。呈现连接正常并不代表 hc 可达。不可用的窗格保留已保存的身份和布局，不会变成替代 shell。

## 共用 hc 机器

通过 hc 检查和管理共用清单（`hc machine ls --json`）。Herdr 在后台刷新，不在窗格渲染路径中查询。名称只用于显示；源端由永久拥有者 core ID 与注册表 core ID 标识。改名不会改变绑定；更换拥有者、注册表或路由不能静默接管旧布局。

没有已保存原生布局的机器，会把现有 **live、源端本地程序各呈现为一个标签页**。这是附加视图，不是启动新 shell，也不会导入其他应用的 PTY 或布局。已有原生布局保持不变，结束历史不会当作 live 导入。空的远程源端保持为空，直到你明确创建工作区。明确关闭窗格会终止那个准确的共用程序；退出或失去 Herdr 连接则只分离视图。

支持直接 SSH 机器。提供器命令（`via`）传输会拒绝操作，不会被改当成 SSH。源端状态、输入主导权与尺寸行为必须兼容已安装的 hc；连接成功本身不代表多视图行为已验证。

下方的已保存配置命令保留给 **明确指定的旧版或自定义源端**，包括并存的 `--hc-path`。共用注册表已有的机器不需要这些命令，这些命令也不会修改共用注册表。

## 连接前的准备

先验证普通 SSH 连接：

```bash
ssh workbox
```

`workbox` 可以是 SSH 配置中的别名，也支持 `ssh://you@server:2222` 这样的目标。添加机器前，请先在源机器安装兼容的 `hc`。Herdr 检查 hc API，不提供远程 Herdr 安装器，也不会静默更新 hc。

当前源端启动路径使用 POSIX shell 和源端的 `/usr/bin/env`。macOS 与 Linux 源端路径已有原生 smoke 测试覆盖；Windows 源端启动尚未验证。认证和主机密钥批准仍由 OpenSSH 负责。有口令的密钥应在后台连接需要它之前通过 `ssh-add` 加载。

## 添加机器

```bash
herdr machine add workbox
herdr machine add workbox --remote-session agents --label "Build machine"
# 可选：选择源端并存的 hc 可执行文件，然后仍使用正常 UI。
herdr machine add workbox --remote-session agents --hc-path /home/user/.local/opt/hc/bin/hc
herdr
```

`--hc-path` 是可选的绝对**源端可执行文件路径**，不是 shell 命令或本机路径。省略时使用远端 PATH 中的 `hc`。该路径会被保存，供状态检查、重连与 TUI 共同使用。自定义文件缺失或不兼容时会失败，不回退到另一个 hc。使用此字段的配置需要新版本机 Herdr；共享配置前应先更新旧客户端及呈现主机。

`--remote-session` 选择 **hc 源会话**，而不是远程 Herdr 会话。未指定时使用 `default`，不会发现远程 Herdr 会话。默认标签为主机名；命名会话使用 `host/session`。名称已被占用时请指定 `--label`。

设置通过 SSH 验证已安装的 hc，然后保存配置。它不会创建 shell、接管任意现有 hc 终端或重启程序。新配置的本地呈现初始为空，直到你明确创建工作区。重新打开配置时，只恢复拥有已保存 hc 绑定的终端。

每份配置拥有不透明 ID，以及名为 `hc-<profile-id>` 的独立本地呈现会话。呈现主机可以在客户端退出后继续运行。关闭客户端只是分离，不会终止源端程序。

运行 `herdr` 打开 UI。已启用的机器通过现有机器侧边栏显示，各自独立连接。选择另一台机器不会移动或重启程序。

## 切换机器

在侧边栏选择机器或它的工作区。选中的机器接收窗格输入和尺寸更新。其他已连接机器继续更新元数据，不传输隐藏窗格的画面。

点击机器旁的箭头可折叠或展开工作区列表，不切换当前机器。键盘导航使用 `prefix+w`，高亮工作区后按 Enter 激活；Esc 或前缀键取消。仅高亮不会改变窗格、标签页、工作区或自定义命令快捷键的目标。

Local 独立于已保存机器的故障。停滞的源端不会从正在使用的机器抢走选择。多个客户端仍可选择不同标签页；参阅[客户端与服务器](/zh-cn/docs/concepts/#客户端与服务器)。

## 安全地重连与关闭

源端传输中断会分离查看端，不会停止程序。Herdr 重连传输后，按每个终端的**永久 hc core ID 和规范终端地址**异步重新附加。公开的工作区、标签页和窗格 ID 是呈现身份，不是 hc 地址。

恢复不会重试结果不确定的 `terminal.run`、重放输入、恢复智能体、导入旧 PTY，或改用源内地址相同的另一个终端。终端缺失、core 不匹配、绑定格式错误或源端离线时，保留原布局和绑定并显示不可用。没有明确上报 hc 状态的程序保持未知；Herdr 不通过屏幕或本地 PID 推断状态。

源端重试从 500 毫秒开始退避，最大 30 秒；连接健康持续一分钟后重置。终端附加尝试有独立的并发限制且可取消。客户端到呈现主机的现有重连策略与此源端重试循环相互独立。

明确关闭窗格、标签页、工作区或弹出窗格，可以终止其精确绑定的 hc 程序。只有 hc 确认终止或有效确认程序不存在后，才移除布局和绑定。离线或结果不确定时，保留它们并报告关闭失败。关闭最后一个窗格也不会创建替代 shell。

## 重命名、禁用或移除

从目录读取配置 ID，不要根据标签或主机名推测：

```bash
herdr machine list
herdr machine list --json
herdr machine rename <profile-id> --label "New name"
herdr machine disable <profile-id>
herdr machine enable <profile-id>
herdr machine remove <profile-id>
```

重命名修改标签，不改变程序身份。禁用保留配置，移除则忘记配置；两者都会分离该源端，但不终止它的 hc 程序，也不影响其他机器。移除或禁用当前选中的机器会返回 Local；Local 不可用时显示其不可用或重连状态，不会选择无关的远程机器。

路由（包括 hc 可执行文件路径，即使仍连接同一 core）或永久 core ID 改变时，旧的本地源主机会退役。新主机拥有新的实例身份，过期请求会被拒绝，不会转发给替代实例。修改目标绝不会让旧 `t1` 绑定获得另一个 core 的 `t1` 的控制权。

## 连接问题

```bash
herdr machine status [<label-or-id>] [--json]
herdr machine reconnect <label-or-id>
```

Status 非交互式检查已安装的 hc。Reconnect 完成受支持的原生 SSH 认证并验证 hc，不安装或更新 Herdr 或 hc。后台连接要求已知主机密钥，绝不回答认证或主机密钥提示。启用托管 SSH 认证传输时会复用它；只读连接失败后的修复只能退役已证明过期且仍属于当前操作的托管监听器，不会停止现有 SSH 会话或 hc 程序。点击错误或重连徽章可重试并查看当前通知。其他机器仍可使用。

hc 缺失或不兼容时，请明确更新源端 hc。本地呈现主机缺少必要 API 时，请更新**本地 Herdr**。不要为了修复已保存的 hc 连接而替换远程 Herdr 服务器。停止本地呈现主机会分离查看端，hc 程序仍留在源端。

目录不可读或无效时，必须先修复配置才能激活改变后的路由。现有客户端连接保留各自隔离的生命周期；配置错误不授权停止无关服务器。

## 源端路径与可用操作

隐式 shell 使用源端 `SHELL`，缺省为 `/bin/sh`，不使用客户端 shell 路径。默认 Home／当前目录行为由源端解析；跟随目录使用 hc 上报的 cwd。明确指定的路径和 argv 都是源端值，不会使用客户端主目录展开。

终端命令通过 hc 执行。Herdr 不向源端复制可执行文件、配置、命令插件或机密。源端程序不会收到本地呈现主机的 API socket、可执行文件路径、窗格身份或本地 SSH-agent 代理路径；源端自身的 SSH-agent 环境保持不变。使用源端 `hc` 管理其运行时，或在本地客户端使用指定机器的 Herdr 命令。命令缺失会明确报错。此适配器暂不提供源端 Git 发现和 worktree 文件系统操作：会拒绝或省略，不会通过操作同名本地路径来替代。

工作区、标签页、窗格 ID 和智能体名称属于各自呈现主机。两份配置都可能包含 `w1:p1`。在 UI 中选择机器不会改变已有窗格中 CLI 的目标。自动化应在每次命令中使用相同机器前缀：

```bash
herdr --machine <label-or-id> agent list
herdr --machine <label-or-id> workspace list
```

CLI 不要求打开 TUI。它把已保存配置解析为本地源主机，并将后续请求绑定到该主机实例。对于已解析的请求，主机重启是错误，不代表可以重新发现目标并重放变更。

## 保存的数据与旧程序

目录只保存配置 ID、标签、SSH 目标、hc 会话和启用状态，不存储密码、私钥或 SSH 控制 socket。绑定与呈现布局另行保存。Snapshot 版本 4 防止旧版 Herdr 将 hc 绑定当作旧运行时的重新启动指令。

现有旧版 Herdr 程序**不会被导入、重启或接管**。hc 没有公开的 live-PTY 导入 API。在你明确安排切换前，请保持旧服务器运行；修改已保存机器的配置不会迁移旧 Herdr 终端。不支持 live PTY handoff，也不支持通过旧进程管理路径删除 hc worktree。
