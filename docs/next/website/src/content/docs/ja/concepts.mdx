Herdr はターミナルワークスペースマネージャーです。hc が実際のプログラムとターミナル状態を所有し、Herdr が正確な接続先バインディングの周りに表示、レイアウト、入力経路を提供します。

## ワークスペース

ワークスペースは最上位のプロジェクトコンテナです。リポジトリ、タスク、調査ごとにひとつのワークスペースを使ってください。

ワークスペースはタブとペインを所有します。サイドバーの状態は内部のエージェントから集約されるので、どのプロジェクトが注意を必要としているかが分かります。

## タブ

タブはワークスペース内のレイアウトです。`agents`、`logs`、`server`、`review` のようにビューを分けるために使います。

タブは CLI とソケット API からアドレス指定できます。

## ペイン

ペインは恒久 core ID と正規の接続先ローカルアドレスでバインドした hc ターミナルを表示します。Herdr はローカル子プロセスを所有せず、出力の描画と入力の転送を行います。デタッチ後もバインディングを保持し、明示的なクローズでは確認後にそのプログラムだけを終了できます。

ペインは右または下に分割できます。手動での名前変更、CLI からの読み取り、入力の送信、クローズができます。

## マウス UI

Herdr はマウスネイティブです。ペイン、タブ、ワークスペース、エージェントをクリックできます。分割境界のドラッグ、テキスト選択、右クリックメニューも使えます。以下で説明する操作はすべてマウスでも行えます。キーボードバインドは任意のレイヤーです。

キーボードのみで操作したい場合や、Herdr にマウス入力をキャプチャさせたくない場合は、マウスキャプチャを無効にしてください:

```toml
[ui]
mouse_capture = false
```

## エージェント

hc ペインのエージェント識別と意味上の状態は、OSC 7501 を含む接続先 hc の明示的な報告から取得します。画面、クライアントのローカル PID、従来の hook、起動予定からは推測しません。ライブのアタッチ上で現在の報告がなければ `unknown` です。

エージェントの状態は次のとおりです:

| 状態 | 意味 |
| --- | --- |
| `blocked` | エージェントが入力、承認、または判断を必要としている。 |
| `working` | エージェントが実行中。 |
| `done` | 接続先が完了を明示的に報告した。 |
| `idle` | 接続先が idle を明示的に報告した。 |
| `unknown` | 利用可能な現在の状態がない、または認識できない。 |

hc ペインを表示・フォーカスしても接続先の `done` は `idle` に変わりません。クライアントの注意マーカーは表示上の情報です。通知はライブの報告による状態変化だけで発生し、再接続で完了通知を再生しません。状態は全バックグラウンド作業の完了証明でも、プロンプトへの承認でもありません。

## セッション

セッションは永続的な Herdr サーバーの名前空間です。デフォルトの `herdr` コマンドはデフォルトセッションにアタッチします。

Herdr の名前付きセッションは独立した表示名前空間であり、hc core の識別情報ではありません:

```bash
herdr session list
herdr session attach work
herdr session attach side-project
```

まずはワークスペースを使い、表示ペイン、ソケット、保存レイアウトを分ける場合に名前付きセッションを使います。プログラムは引き続き hc 接続先が所有し、Herdr のセッション名変更でバインディングを変更することはありません。

## クライアントとサーバー

デフォルトでは、Herdr はバックグラウンドサーバーと、それにアタッチした 1 つ以上のクライアントとして動作します。

Herdr ホストはレイアウトと表示を所有し、クライアントはそのターミナル UI です。hc は独立してプログラム、ターミナル状態、cwd、報告状態を所有します。保存済み SSH マシンはローカル Herdr から接続先 hc へ SSH 接続し、リモート Herdr の描画は使いません。

クライアントが 1 つだけ接続されている場合、従来どおりすべてのタブがそのサイズに従います。複数のクライアントが接続されている場合、それぞれ別のワークスペースやタブを表示できます。異なるタブはそれぞれを表示するクライアントのサイズに従い、同じタブを表示している場合は、最後にそのタブへフォーカス、選択、または操作したクライアントがペインのサイズを制御します。

`ctrl+b q` でクライアントをデタッチします。サーバーとエージェントは動き続けます。

hc プログラムを維持して表示ホストだけを停止するには:

```bash
herdr server stop
```

バインド先プログラムの終了にはペインを明示的に閉じます。結果が不明ならペインとバインディングを保持します。[セッション状態と復元](/ja/docs/session-state/)を参照してください。

## モード

Herdr にはターミナルモード、プレフィックスモード、ナビゲートモードがあります。

ターミナルモードはフォーカス中のペインにキーを送ります。プレフィックスモードはプレフィックスキーの後に Herdr のアクションをひとつ待ちます。ナビゲートモードは常駐のワークスペースナビゲーション画面です。

プレフィックスキー (デフォルト `ctrl+b`) を押してから、新しいタブなら `c`、ワークスペースナビゲーションなら `w` のようにアクションキーを押します。プレフィックスの考え方が初めてなら[キーボード](/ja/docs/keyboard/)を参照してください。
